# Instructions for Use

If this is your first time, follow these instructions to get the tutorial set up:

1. Create a GitHub account (or login to an existing account if you have one already)
2. Go to the original tutorial repository page (https://github.com/G8L18M/python-tutorial) and click "Fork"
3. Launch your own codespace by clicking on "Code", then "Codespaces", then "Create codespace on main"
4. After the codespace launches in a new tab, click "Trust Folder and Continue"
5. Make a copy of "Blank_Python_Tutorial.ipynb" and change the filename to "Name_Python_Tutorial.ipynb" where "Name" is your name. Then you can open that .ipynb file.
6. When you get a notification in the bottom right to install the recommended Jupyter and Python extensions, click "Install"
7. The first time you run a code block, you will be asked to select a kernel source. Select "Python environments..." then choose either of the Python 3.14.2 enviroments.
8. After completing these setup steps, the code blocks should run normally! Feel free to work through the tutorial now.

If you are picking up from where you left off:
1. Login to GitHub
2. Under "Top repositories", look for your python tutorial repository and click on it
3. Click on "Code". If your codespace is still there, open the one that you have. Otherwise, start from step 3 in the above list of steps to set up your codespace again.

To save changes to your repository, go to your codespace and run the following commands in the terminal. Make sure to change "Name" to your name, and feel free to customize the commit message.
1. git add "Name_Python_Tutorial.ipynb"
2. git commit -m "Commit message here"
3. git push origin main
